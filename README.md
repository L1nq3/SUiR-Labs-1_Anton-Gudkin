# Lab-1 ГУДКИН АНТОН 
## Лабораторная работа №1

* не хотел оставлять работу без комментариев, так что сделал небольшое описание основных моментов

**Задание №1**

* За пиксель взята строка из двух пробелов
* Зеленая полоса на весь флаг, так что на нее условия нету
* В середине желтая полоса меняется на красную 

**Задание №2**

* Сначала пользователь вводит цвет по номеру
* За пиксель взята строка из двух пробелов
* Ромбы определяются не закрашенной часть а уменьшением пустого сектора (sector) 
* закрашенную часть определяет разность axis - sector, где axis это расстояние от края до вертикальной диагонали первого ромба
* Так как ромбы сливаются друг с другом, то в середине вместо sector применяется mid_sector, эта переменная заранее уменьшает зазор между ромбами, за счет этого ромбы сливаются как на картинке

**Задание №3**

* В данном задание задана функция animation которая посменно меняет 4 кадра анимации и задерживаетса на каждом из них на 0.5 секунды
* Анимация представляет собой вращаюшийся вентилятор с четырмя лопостям 2 цветов
* В первом и третьем кадре лопости парралельны краям вентилятор, во втором и четвертом лопсти образуют крест
* Анимация бесконечна за счет цикла вида: WHile True

**Задание №4**

* В начале цикла выводится и выравнивается номер столбца (Y координата)
* Принадлежность пикселя точки графику проверяется отношение к графику путем подстановки в уравнение функции y = x+1
* переменная add создает отступ для первого пикселя, а далее все пишутся уже в четком ряду
* снизу выводиться сначало ноль в столбце координат Y, а затем под графиком выводиться строка координат X
